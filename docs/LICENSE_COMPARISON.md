## Comparison (historical)

| Option | Outcome |
|--------|---------|
| **Apache-2.0** | **Selected** — commercial use, modification, redistribution; express patent license + patent termination; notice preservation |
| MIT | Not selected — simpler, but no explicit patent grant |
| Proprietary source-available | Not selected — would weaken open-kit adoption |

## Practical summary for users

- Personal and commercial use: **allowed**
- Modification: **allowed**
- Redistribution: **allowed** (keep license + required notices)
- Purchase Pro to use Community: **not required**
