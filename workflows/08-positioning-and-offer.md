# Workflow 08 — Positioning & offer

## Objective

Sharpen positioning and offer packaging from verified inputs. Do not advertise unvalidated capabilities or final pricing.

## Inputs

- Business profile
- ICP (03), research (02), discovery (07) if available

## Process

1. State current positioning in one sentence from owner materials.
2. Propose positioning options with tradeoffs. Mark each claim’s basis.
3. Define offer ladder (core, add-ons) only from owner-approved components.
4. Pricing: if not validated, present **hypotheses** with validation tests — never “official price.”
5. List banned/unvalidated claims to keep out of campaigns.
6. Produce messaging pillars + proof map (proof only where evidence exists; else `unknown`).
7. Schema: `schemas/positioning.schema.json`.

## Output format

1. **Objective**
2. **Verified findings**
3. **Evidence / sources**
4. **Recommendation** (primary positioning to test)
5. **Next actions**
6. **Confidence & missing info**

## Guardrails

- Unvalidated partners, certifications, or results must not appear as facts
- Testimonials only if owner-provided and permitted
- Synthetic demos labeled **SYNTHETIC**

## Done when

- One recommended positioning for testing
- Clear list of claims that are blocked until validated
- Handoff to workflows 09/10
