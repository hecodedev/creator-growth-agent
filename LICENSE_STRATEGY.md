## What Apache 2.0 allows

- **Commercial use** — permitted
- **Modification** — permitted
- **Redistribution** — permitted (Source or Object form)
- **Private use** — permitted

## What Apache 2.0 requires (high level)

- Preserve the **License** and applicable **copyright / patent / attribution notices** when you redistribute
- State changes in modified files
- If a `NOTICE` file is distributed with the Work, include the required attribution notices in Derivative Works (see License §4)

## Patent terms (express)

Apache 2.0 includes an **express patent license** from each Contributor (License §3) and **patent license termination** if you institute patent litigation alleging the Work or a Contribution infringes (same section).
